# Mail Peek — Chrome Web Store listing copy

## Name
Mail Peek

## Summary (short)
See Outlook .msg/.eml exactly as written—body, images, From/To/Cc, dates & reply separators. No Outlook. No download first.

---

## Detailed description (formatted)

**Open any Outlook email file and see it exactly as it was meant to be read.**

Mail Peek brings true fidelity email preview to Chrome. Click a `.msg` or `.eml` filename and the message opens in a clean popup—**no Microsoft Outlook, no “Save as…”, no clutter in your Downloads folder.**

### 100% faithful preview
What you see is what was in the mail:

- **Full message body** restored, including rich HTML layout  
- **Inline images** shown in place (signatures, screenshots, logos—not broken icons)  
- **Images at full size** — wide pictures keep their original aspect ratio; scroll or swipe horizontally inside the preview instead of being squeezed  
- **From / To / Cc** in the correct order, just like Outlook  
- **Sent time** clearly displayed  
- **Reply & forward separators** preserved so every message in a long thread stays easy to tell apart  

Long threads stop being a wall of text. Each turn is readable. Images load. Headers match the original file.

### Built for real work
Perfect when emails live as attachments in **Jira**, shared folders, or ticket tools. Click to read. Zoom the preview with **Ctrl/⌘ +/−** without changing the page. Hold **Shift** if you still need the original download—normal downloads always keep working, and a web app’s own **Preview / Download / 预览 / 下载** buttons always run that app’s own action.

### Reply without leaving the page
**Reply, Reply all and Forward** buttons right in the preview. One click hands the original email — every byte of it — to *your* default mail app (Outlook, if that is what opens .msg/.eml files), so you reply there with full formatting, images and attachments intact. No dialogs, no hunting through Downloads. Mail Peek itself never sends anything.

### Privacy by design
Parsing happens **locally in your browser**. Your mail never gets uploaded to our servers.

**Mail Peek — email files, finally readable at a glance.**

Also supports optional preview of `.html` attachments (e.g. chat logs).

Mail Peek is free. If it saves you time, you can support development at buymeacoffee.com/spikesu.
